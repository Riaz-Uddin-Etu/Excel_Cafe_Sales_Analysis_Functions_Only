# ☕ Excel_Cafe_Sales_Analysis_Functions_Only

## 📊 Project Overview
This project showcases my ability to clean, transform, and analyze real-world business data using **only Microsoft Excel**.  
The dataset (`dirty_cafe_sales.xlsx`) contained messy and inconsistent café sales records.  
I cleaned the data, applied **50+ Excel formulas**, and created an **interactive analysis workbook** to answer business questions.

## 🛠️ Skills Demonstrated
- Data Cleaning with Excel UI tools:
  - Remove Duplicates, Flash Fill, Find & Replace
  - Conditional Formatting
  - Removing invalid rows (`Unknown`, `Error`, blank values)
- Formula mastery:
  - **Math & Aggregation:** `SUM`, `AVERAGE`, `COUNTIF`, `SUMIFS`, `AVERAGEIF`, etc.
  - **Lookup & Reference:** `VLOOKUP`, `XLOOKUP`, `INDEX`, `MATCH`
  - **Text Functions:** `LEFT`, `RIGHT`, `MID`, `LEN`, `PROPER`, `UPPER`, `LOWER`, `SUBSTITUTE`, `TEXTJOIN`
  - **Logical & Conditional:** `IF`, `IFS`, Nested IF
  - **Date & Time:** `NOW`, `TODAY`
  - **Others:** `UNIQUE`, `CLEAN`, `REPLACE`, and `TRIM()` for whitespace removal
- Descriptive Statistics with formulas:
  - `MEDIAN`, `STDEV`, `MIN`, `MAX`
